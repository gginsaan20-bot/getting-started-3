# Commute Tracker
Deploy: upload this folder to GitHub → Railway → New Project → Deploy from GitHub repo → select repo → Settings / Networking / Generate Domain.

Run locally with Node.js 18+: `npm install && npm start`, then visit http://localhost:3000.

**Storage:** This starter uses browser localStorage. Records remain in that browser/device only. Export JSON backups regularly. It does not synchronize across devices; add Railway PostgreSQL for shared/server-side persistence.
